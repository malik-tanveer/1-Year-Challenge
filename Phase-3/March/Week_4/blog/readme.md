# Blog Project **Documentation** & Setup Guide
This document provides an overview of the Blog Project, including its features, setup instructions, and usage guidelines.

## Project Overview
The Blog Project is a web application designed to allow users to create, manage, and share blog
posts. It includes features such as user authentication, post creation and editing, commenting, and a responsive design for mobile and desktop users.

## Features
- User Registration and Authentication
- Every user can create, edit, and delete their own blog posts
- Commenting system for users to engage with posts
- Responsive design for optimal viewing on various devices
- Search functionality to find posts by keywords
- Admin panel for managing users and posts
## Technology Stack
- Frontend: Next.js, React, Tailwind CSS, Shadcn
- Backend: Node.js, Express.js
- Database: MongoDB

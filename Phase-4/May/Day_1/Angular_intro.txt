# What is Angular?

Angular is a framework used to build:

* Web applications
* Dashboards
* Admin panels
* Enterprise applications
* Single Page Applications (SPAs)

It provides many features out of the box:

* Components
* Routing
* Forms
* HTTP Requests
* Dependency Injection
* State Management tools
* Authentication support

---

# Angular vs React

### React

* More flexible
* You choose many libraries yourself
* Easier to start
* UI-focused

### Angular

* More structured
* Includes many built-in features
* Better for large-scale applications
* Architecture-focused

---

# New Concepts You Will Learn in Angular

### 1. Components

Components are reusable UI blocks.

```ts
@Component({
  selector: 'app-user',
  template: '<h1>Hello</h1>'
})
export class UserComponent {}
```

---

### 2. Services

Services contain business logic and API calls.

```ts
@Injectable()
export class UserService {}
```

---

### 3. Dependency Injection (DI)

Angular automatically provides services to components.

```ts
constructor(private userService: UserService) {}
```

---

### 4. Lifecycle Hooks

Similar to React's `useEffect()`.

```ts
ngOnInit() {}

ngOnDestroy() {}
```

---

### 5. RxJS

One of the most important Angular concepts.

You will learn:

* Observable
* Subject
* BehaviorSubject
* pipe()
* subscribe()
